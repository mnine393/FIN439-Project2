# Data card: Consumer Price Index for All Urban Consumers, All Items

- Source: Federal Reserve Bank of St. Louis ALFRED, [CPIAUCSL](https://alfred.stlouisfed.org/series?seid=CPIAUCSL), retrieved with the ALFRED graph download using the decision-date vintage.
- What it measures: the Consumer Price Index for All Urban Consumers, All Items, seasonally adjusted.
- Units: index, 1982–1984 equals 100.
- Publication lag: about two weeks after the end of the measured month.
- Revisions: each February, seasonal adjustment changes revise roughly five years of history. The application uses the saved decision-date vintage, not values revised today.
- Download date: recorded by the saved file's creation time when the application first downloads it.
